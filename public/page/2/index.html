keyboard freeze

Another potential fix to my keyboard freezing problem on Linux Mint 22.1 after going to sleep. Edit Grub. sudo vi /etc/default/grub Add i8042.dubkdbd=1 to the GRUB_CMDLINE_LINUX_DEFAULT. GRUB_CMDLINE_LINUX_DEFAULT="usbcore.autosuspend=-1 quiet splash i8042.dumbkbd=1" Update Grub and reboot. sudo update-grub reboot Hopefully that fixes it.

copy paste nvim

How to copy and paste in vim or nvim. Let’s say you have 10 rows of code that you want to copy somewhere else like at the bottom of your code. Press Esc to enter Normal mode. Move the cursor to the first line. Enter Visual Line mode. Shift+V. Move cursor or letter j or k. Press y to yank the selected lines. Move the cursor to your target location. Press p to paste after the current line. Or P to paste before the current line. Esc Move cursor Shift+V Move cursor y Move cursor p or P u If you want to undo, press u.

run node anywhere

Run your node script from anywhere by switching to a specific directory by changing to a working directory. Place this code at the top of your node script. #!/usr/bin/env node process.chdir('/absolute/path/to/your/directory'); console.log('Now running in:', process.cwd()); In addition, you can also add your node directory to your PATH so you can run it anywhere. export PATH=$PATH:/absolute/path/to/your/directory If you want it to be more permanent, add the export command to your ~/.bashrc in Linux or ~/.zshrc on a Mac.

feeding the starter

Feeding the sourdough starter (the beast). Take out 80% of the starter and throw it away or use it on other breads. Add 50 grams of flour to the starter. Add 50 grams of filtered water to the starter. Mix it thoroughly for 30 seconds or so. Place in the fridge until the next feeding or use. Feed your starter at least once a week.
