matrox monarch configuration

You can import the Matrox Monarch HD configuration on boot up from a web page. Go to: Command Center > Automatic Configuration. Type in URL Address starting with https. Check "Load settings on device reboot." You can either power off the device or hit reset. Holding reset for more than 5 seconds does a factory reset. On next bootup, device will have configuration contained from the remote file.
