vi search and replace

How to do search and replace in Vim. Search for “foo” and replace it with “bar” in the current line. Use :s :s/foo/bar/g Search for “foo” and replace it with “bar” in the entire document. Use :%s :%s/foo/bar/g You can also pipe instead of forward slash. Useful if your search contains a /. :%s|foo/|bar|g

redhat 8 network manager

In Redhat 8, every time you the Network Manager get’s restarted it overwrites /etc/resolv.conf. To prevent that from hapenning, create a new file called /etc/NetworkManager/conf.d/90-dns-none.conf and add the following lines. Restart Network Manager. Your /etc/resolv.conf should be unchanged. [main] dns=none Restart Network Manager $ systemctl reload NetworkManager

python virtual environment
