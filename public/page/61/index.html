gcp start multiple instances

Here’s how to start multiple instances using Bash and Google SDK. #!/bin/bash while IFS=', ' read -r a b c; do instance="${a//[[:blank:]]/}" project="${b//[[:blank:]]/}" zone="${c//[[:blank:]]/}" echo "Starting $instance ...." gcloud compute instances start $instance \ --zone $zone --project $project --async done Instances are read from an external file. The file format is displayed below. server1,project1,us-central1-a server2,project2,us-central1-b server3,project3,us-central1-c To stop multiple instances, replace “start” with “stop.”

gcp check instances running

Here’s how to check if instances are running in GCP. #!/bin/bash while IFS=', ' read -r a b c; do instance="${a//[[:blank:]]/}" project="${b//[[:blank:]]/}" zone="${c//[[:blank:]]/}" gcloud compute instances describe $instance \ --zone $zone --project $project \ --format='table[no-heading](name,status,zone)' done Instances are read from an external file. File is comma delimited with instance name, project id and zone data.
