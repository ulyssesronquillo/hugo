wordpress 3.7 auto updates

Starting with WordPress 3.7, you don’t have to lift a finger to perform a WordPress update. Most WordPress-powered websites will be able to perform automatic updates without any intervention. The only prerequisite is that your website is capable of carrying updates without entering your FTP credentials. In the future, WordPress may require users to click “Update Now” for major feature releases. The good news is, several of my WordPress-powered websites were able to perform auto updates automatically without a hitch. WordPress, as a courtesy, does send out an email notifications to WordPress administrators after each upgrade is completed. This new feature will be a tremendous help for many administrators who manage dozens of websites, knowing WordPress updates are going to be done automatically.

open with application duplicate

If you’re a Mac user, you can open up a file by right-clicking on it, and choosing “Open With,” and selecting an application. If you see duplicates, you can remove multiple entries by running the following script. The script restarts the Launch Register called lsregister and removes the duplicates. /System/Library/Frameworks/CoreServices.framework/Frameworks/LaunchServices.framework/Support/lsregister -kill -r -domain local -domain system -domain user Right click the file again. The duplicates should be gone.
