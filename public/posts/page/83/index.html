remmina install

Remmina is the RDP (remote desktop software) for Windows server on Linux. linux mint windows and workspaces

Here’s the shortcut key combination for managing windows and workspaces in Linux Mint 18. Press the “Ctrl + Alt + Down” keys to display all open windows. Press the “Ctrl + Alt + Up” keys to display all workspaces. Press the “Ctrl + Alt + Left or Right” keys to move between workspaces. Very useful.
