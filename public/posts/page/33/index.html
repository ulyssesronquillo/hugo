rocky linux in a container

Here’s how to run Rocky Linux in a Docker container. Download the image. docker pull rockylinux/rockylinux Create a Rocky Linux container called bullwinkle. docker run -it --name bullwinkle -d rockylinux/rockylinux Login to the container using bash. docker exec -it --user root bullwinkle /bin/bash When done, stop and delete the container. docker ps -a docker stop container_ID docker rm container_ID

delete lines using awk

Here’s how to delete a line from a file using awk. awk '!/Redhat/' sample.txt > sample.tmp && mv sample.tmp sample.txt The command above looks for ‘Redhat’ in a file and removes that line from the file. You can add the line in the crontab to run at reboot if you like. crontab -e @reboot awk '!/Redhat/' sample.txt > sample.tmp && mv sample.tmp sample.txt
