Here's another great Terminal or CLI tool for navigating files and directories.

To install, just use your package manager. In this case, it's apt.

```
apt install yazi
brew install yazi
```
To run, just type yazi.

```
$ yazi
```

If text is not readable, search online for catppuccin yazi theme.

Download the file and paste it to ~/.config/yazi/theme.toml.

```
mkdir ~/.config/yazi
touch ~/.config/yazi/theme.toml
vi ~/.config/yazi/theme.toml
```

Rerun yazi. The new theme should be activated.

```
$ yazi
```
