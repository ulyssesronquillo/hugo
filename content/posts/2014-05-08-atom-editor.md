[Github](http://github.com) released yesterday a new editor called [Atom](https://atom.io/). It’s built on HTML, CSS, Javascript and [Node.js](http://nodejs.org/). It’s designed to be extensible via add-on packages so it can be used for a number of things, but it’s mainly used as a text editor. The Atom core, Package Manager and Shell are open-source available via the [MIT license](http://opensource.org/licenses/MIT). Currently is available only on Mac OS, but will be available soon for Windows and Linux.

There are over 800 add-on packages already available from the project’s homepage. If you’re a PHP developer, be sure to add [language-php](https://atom.io/packages/search?q=php), [php-twig](https://atom.io/packages/search?q=php) and [php-beautifier](https://atom.io/packages/search?q=php). Based on the initial review, it seems to be well-received by a number of [reviewers](http://techcrunch.com/2014/05/06/github-open-sources-its-atom-text-editor/). Is there enough here to get developers to move from [Text-Mate](http://macromates.com/) and [Sublime Text Editor](http://www.sublimetext.com/)? We will see. I happen to like it a lot. I plan to use it for the next two weeks.
