I'm sharing by black and white fujifilm simulation called Noir. It's based on Acros +R with DR set to 400. 

Here's the recipe.

* Film Simulation: Across + R
* Monochromatic Color: WC 0, MG 0
* Grain Effect: Off 
* Color Chrome Effect: Off
* Color Chrome FX Blue: Off
* White Balance: Auto
* Dynamic Range: DR400
* D Range Priority: Off
* Tone Curve: H 0, S 0
* Sharpness: 0
* Hign ISO NR: 0
* Clarity: 0
