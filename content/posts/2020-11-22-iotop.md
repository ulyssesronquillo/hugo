iotop is a Linux command similar to top but instead of CPU and memory it will display and monitor your disk IO usage.

To install, run the following command based on your Linux ditro.

```
yum install iotop
apt install iotop
dnf install iotop
```

To use.

```
iotop
iotop -o
```
