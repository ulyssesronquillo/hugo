Looking for a text editor for editing code? Check out [Sublime Text 3](https://www.sublimetext.com/). You can install the text editor using several package managers depending on your Linux distro. There’s apt, yum, zypper, pacman and dnf. Here’s the Apt install of Sublime Text 3.

```
echo "deb https://download.sublimetext.com/ apt/stable/" | sudo tee /etc/apt/sources.list.d/sublime-text.list
sudo apt-get update
sudo apt-get install sublime-text
```
