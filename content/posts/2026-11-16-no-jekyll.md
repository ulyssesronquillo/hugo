Since I switched over from Jekyll to Hugo, a static website generator. Since switching over, I was getting a ton of errors from the build. Also, I'm getting a ton of build fails on my email because I notifications turned on. As it turned out, if you use GitHub Pages, by default, it will automatically assume that you are running a Jekyll build pipeline. To disable Jekyll build, just add a simple empty file called .nojekyll in the root of your repository. If this file is present, the Jekyll build will be ignored. No more errors.
