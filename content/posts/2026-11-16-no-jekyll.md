Since I switched over from Jekyll to Hugo, which is a static website generator. Since switching over to Hugo, I was getting a ton of errors from the build. I'm also getting a ton of build fails via email because I have notifications turned on. Well as it turned out, if you use GitHub Pages, it will automatically assume that you are running a Jekyll build pipeline by default. To disable the Jekyll builds, just simple add an empty file called .nojekyll at the root of your repository. If this file is present, the Jekyll build action will not run. Hence, no more errors.
