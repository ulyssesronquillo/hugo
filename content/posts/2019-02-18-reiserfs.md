Install ReiserFS

```
rpm --import https://www.elrepo.org/RPM-GPG-KEY-elrepo.org
rpm -Uvh https://www.elrepo.org/elrepo-release-7.0-3.el7.elrepo.noarch.rpm
yum update
yum install kmod-reiserfs kmod-reiserfs
```

Make a ReiserFS

```
fdisk /dev/xvdf
n, p, 1
[return]
[return]
mkreiserfs /dev/xvdf1
mount -t reiserfs /dev/xvdf1 /data
```

Other Reiserfs commands

```
reiserfsck /dev/xvdf1
resize_reiserfs /dev/xvdf1
```
