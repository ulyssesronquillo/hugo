I’m thinking about using the Linux desktop again after 4 years of inactivity. The [MacOS](http://www.apple.com/osx/) was the desktop of choice. I’ve been happy with the switch. I don’t anticipate abandoning it any time soon. Lately I thought about sharpening up my Linux skills after having been dormant for years. I need a Linux platform that I can work with. [Ubuntu](http://ubuntu.com) is my default, but there are other distros equally interesting. [Mint](https://www.linuxmint.com/), [Debian](https://www.debian.org/) and [Fedora](https://getfedora.org/) come to mind. Instead of having multiple boot partitions, I might install Ubuntu as the base distro and install [Virtualbox](https://www.virtualbox.org/). Other distros can be fired up as virtual machines. In that way, it’s simple to manage. I just need a heftier machine that can handle several VMs running at the same time. That’s the plan for the next several weeks.
