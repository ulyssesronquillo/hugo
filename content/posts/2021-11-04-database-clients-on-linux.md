You can run database clients on your Linux distro by installing them.

MySQL

```
$ yum install mysql
$ apt install mysql
```

Postgress

```
$ yum install postgresql postgresql-client
$ apt install postgresql postgresql-client
```

MSSQL

```
$ yum install mysql-tools
$ apt install mssql-tools
```
