If you’re new to WordPress and you want to learn more, I recommend you dig into the WordPress Codex, which is the online manual and living repository for WordPress information and documentation. As a newbie, you can start learning how to use WordPress, then work with Themes, and maybe even write a Plugin or two. If that’s not your forte, then maybe you can contribute to the WordPress community by becoming a tester by reporting bugs, or work on the online documentation. See link below.

[WordPress Codex](http://codex.wordpress.org)
