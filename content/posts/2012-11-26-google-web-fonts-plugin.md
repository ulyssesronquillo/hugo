I’m releasing a WordPress plugin called “Web Fonts.” This plugin takes advantage of the free and open-source [Google Web Fonts](http://google.com/webfonts/). If you’re not familiar with Google Web Fonts, it’s a group of fonts that allows designers to customize the looks of their blogs or websites using hundreds of exotic fonts. With a gaggle of external fonts available for use, “Web Fonts” can transform the overall design of a website.

#### Install and Configure

1. Upload the “webfonts” folder to the WordPress plugins folder.
2. Activate the “Web Fonts” plugin from the “Dashboard &gt; Plugins &gt; Installed Plugins.”
3. Configure stylesheet link and CSS from the “Dashboard &gt; Settings &gt; Web Fonts.”
4. If you want multiple fonts, just add a second stylesheet link and additional CSS.
5. “Update Options” to save.
