Style your text using markdown. If you use GitHub, markdown will come in handy.

Examples:

```
# This is an <h1> tag
## This is an <h2> tag
###### This is an <h6> tag
</h6></h2></h1>
```

Here are more [markdown examples](https://guides.github.com/features/mastering-markdown/#examples).
