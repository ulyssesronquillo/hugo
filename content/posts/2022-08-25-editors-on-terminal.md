How to run editors from the Terminal.

Sublime, Visual Studio Code, Atom and Bluefish examples.

Open from the current directory.

```
subl .
code .
atom .
bluefish .
```

Open editor using path and file.

```
subl /etc/hosts
code /etc/hosts
atom /etc/hosts
bluefish /etc/hosts
```
